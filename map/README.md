# 丝路智境 · 甘肃段丝路文化地图（数据可视化模块）

《丝路智境》数字媒体竞赛作品的核心模块之一：基于 **ECharts + 真实地理数据** 的丝绸之路甘肃段文化地图。

---

## 一、怎么运行（30秒启动）

```bash
# 1. 进入目录
cd 丝路智境-文化地图

# 2. 启动静态服务器（必须用HTTP访问，浏览器file://会因跨域失败）
python -m http.server 8100

# 3. 打开浏览器
#    http://127.0.0.1:8100
```

> 全部资源已本地化（ECharts 库、甘肃 GeoJSON、点位数据均在本目录），**离线可运行**，现场演示不依赖网络。

## 二、功能与交互

| 能力 | 说明 |
|---|---|
| 甘肃地图 | 基于真实省级 GeoJSON（含14市州边界），深色敦煌风配色 |
| 三大图层 | 丝路路线 / 石窟分布 / 丝路重镇，可单独切换或叠加 |
| 点位标注 | 石窟8处（◇）、丝路重镇7城（●）、关隘2处（▲）三类分色编码 |
| 丝路路线 | 主线（天水→兰州→武威→张掖→酒泉→嘉峪关→敦煌→玉门关）+ 南北两道，自东向西流光动画 |
| 点击交互 | 点击任意点位 → 右侧详情面板显示简介、朝代、数据来源 |
| 点位列表 | 左侧列出全部17个点位（分类色标），点击即查看详情并聚焦地图 |
| AI 文化追问 | 详情面板"向AI助手追问"按钮 → 跨域调用 AI 助手 API，回答渲染在右侧（需 AI 助手运行于 8000 端口） |
| 宣传片入口 | 顶栏"观看宣传片"→ 播放《丝路智境》15秒宣传短片（media/ 目录，两段顺序播放） |
| 数据速览 | 实时统计：石窟8 / 重镇7 / 关隘2 / 路线3 |
| 响应式 | 窄屏自动切换为上下布局，手机可看 |

## 三、目录结构

```

└── data/
    └── sites.json      # 点位与路线数据集（含数据来源字段）
```

## 四、数据来源（可核验，回应评分标准）

1. **地图边界**：阿里 DataV 公开地理数据（`620000_full.json`，省级边界）；
2. **点位坐标**：公开地理坐标（WGS84，参考 OpenStreetMap / 维基百科坐标）；
3. **内容简介**：依据敦煌研究院、甘肃省文物局及各遗产地官网公开资料整理；
4. **图表库**：Apache ECharts 5.4.3（开源）。

数据集 `data/sites.json` 中每个点位均带 `source` 字段，页面详情面板与页脚同步展示来源——符合"数据来源、信息结构、视觉编码"的可视化作品要求。

## 五、信息结构与视觉编码

- **路线图层**：丝路主线（甘肃段）与南北两道，自东向西流向（金色主光流）；
- **点位图层**：石窟（◇ 紫蓝）、重镇（● 金）、关隘（▲ 红），形状+颜色双重编码；
- **详情交互**：点击点位查看简介、朝代与数据来源。

## 六、评委演示脚本（建议）

1. 打开页面（30秒）：介绍"这是基于真实地理数据的甘肃段丝路文化地图"；
2. 切换图层（1分钟）：依次展示"石窟分布→丝路重镇→丝路路线"，说明视觉编码逻辑（形状+颜色分类）；
3. 点击点位（1分钟）：点莫高窟/玉门关，展示详情面板中的简介、朝代、**数据来源**；
4. 讲数据（30秒）：展示地图边界、点位坐标、内容简介三层次来源，强调"每条数据可核验"；
5. 讲技术（30秒）：ECharts + GeoJSON 本地化渲染，离线可运行。

## 七、与 AI 助手联动

地图与 AI 助手（`丝路智境-AI助手` 模块）已打通：

1. 先启动 AI 助手：`cd 丝路智境-AI助手 && python app.py`（8000 端口）
2. 再打开本地图（8100 端口）
3. 点击任一点位 → 详情面板出现"向 AI 助手追问"按钮 → 点击后 AI 回答显示在地图页右侧

跨域已通过 CORS 打通（AI 助手 app.py 已加 `Access-Control-Allow-Origin: *`）。若 AI 助手未启动，追问面板会给出启动提示。
